Create the FastAPI backend

Create a backend/ folder and add main.py. The most critical part is CORS — without it, the browser will block ALL requests from React (port 5184) to FastAPI (port 8011).

backend/main.py
from fastapi import FastAPI, HTTPException
from fastapi.middleware.cors import CORSMiddleware
from pydantic import BaseModel

app = FastAPI(title="Actoryx Employee API")

# ⚠️ STEP 1 — Add CORS BEFORE any routes
app.add_middleware(
    CORSMiddleware,
    allow_origins=["http://localhost:5184"],  # React dev server
    allow_methods=["*"],
    allow_headers=["*"],
)

# In-memory database (list of dicts)
employees_db = [
    {"id": 1, "name": "Ravi Kumar",   "role": "React Intern",    "department": "Engineering", "email": "ravi@actoryx.com"},
    {"id": 2, "name": "Priya Sharma", "role": "UI Intern",       "department": "Design",      "email": "priya@actoryx.com"},
]

class EmployeeCreate(BaseModel):
    name: str;  role: str;  department: str;  email: str

@app.get("/employees")
def get_employees():
    return employees_db

@app.post("/employees", status_code=201)
def create_employee(emp: EmployeeCreate):
    new = {"id": len(employees_db) + 1, **emp.model_dump()}
    employees_db.append(new)
    return new

@app.put("/employees/{emp_id}")
def update_employee(emp_id: int, emp: EmployeeCreate):
    for i, e in enumerate(employees_db):
        if e["id"] == emp_id:
            employees_db[i] = {"id": emp_id, **emp.model_dump()}
            return employees_db[i]
    raise HTTPException(404, "Not found")

@app.delete("/employees/{emp_id}")
def delete_employee(emp_id: int):
    for i, e in enumerate(employees_db):
        if e["id"] == emp_id:
            employees_db.pop(i)
            return {"message": "Deleted"}
    raise HTTPException(404, "Not found")

💡 Why Axios instead of fetch()?

Axios automatically parses JSON responses into response.data, handles errors more cleanly, and supports request/response interceptors for auth tokens — all without extra boilerplate.

Create the API module — src/api/employeeApi.js

Keep all Axios calls in one file. This way, if the API URL changes, you only update one place. Use .env for the base URL — never hardcode it.

.env
VITE_API_BASE_URL=http://localhost:8011
src/api/employeeApi.js
import axios from 'axios'

const BASE_URL = import.meta.env.VITE_API_BASE_URL || 'http://localhost:8011'

export const getEmployees   = ()        => axios.get(`${BASE_URL}/employees`)
export const createEmployee = (data)    => axios.post(`${BASE_URL}/employees`, data)
export const updateEmployee = (id, data) => axios.put(`${BASE_URL}/employees/${id}`, data)
export const deleteEmployee = (id)      => axios.delete(`${BASE_URL}/employees/${id}`)

Fetch data with useEffect + Axios

useEffect with an empty [] dependency array runs once after the first render — perfect for fetching data on page load. Always handle loading and error states.

src/pages/EmployeePage.jsx — fetch pattern
import { useState, useEffect } from 'react'
import { getEmployees } from '../api/employeeApi'

function EmployeePage() {
  const [employees, setEmployees] = useState([])
  const [loading,   setLoading]   = useState(true)
  const [error,     setError]     = useState('')

  useEffect(() => {
    fetchEmployees()
  }, [])  // ← empty array = run once on mount

  const fetchEmployees = async () => {
    try {
      setLoading(true)
      const res = await getEmployees()
      setEmployees(res.data)        // Axios puts JSON body in .data
    } catch {
      setError('Failed to load. Is the backend running on port 8011?')
    } finally {
      setLoading(false)            // always runs — hides spinner
    }
  }

  if (loading) return <p>Loading…</p>
  if (error)   return <p style={{color:'red'}}>{error}</p>

  return (
    <table>
      {employees.map(emp => (
        <tr key={emp.id}>
          <td>{emp.name}</td>
          <td>{emp.role}</td>
        </tr>
      ))}
    </table>
  )
}
💡 key prop

Always add key={emp.id} to list items. React uses it to efficiently update only the rows that changed, instead of re-rendering the whole table.

⚠️ #1 Blocker — CORS error

If you see "Access to XMLHttpRequest blocked by CORS policy" in the browser console — you forgot to add CORSMiddleware in FastAPI, or the React port (5184) is not in allow_origins. Fix it in backend/main.py and restart uvicorn.

⚠️ Port Note

Always use port 8011 for the FastAPI backend across all workshops. Test every endpoint at http://localhost:8011/docs (Swagger UI) before connecting from React.
