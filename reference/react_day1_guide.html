Workshop 1 — Hello World App

Understand project structure, JSX, Components, and Props
1

Create the project with Vite

Open your terminal and run these commands one by one. Vite creates a React project with near-instant hot reload — much faster than the old Create React App.

Terminal
npm create vite@latest workshop1-hello-world -- --template react
cd workshop1-hello-world
npm install
npm run dev
💡 Why Vite?

CRA (Create React App) uses Webpack and takes 30–60s to start. Vite uses native ES Modules — dev server starts in under 1 second.

2

Understand the folder structure

After setup, your project looks like this. Every file has a specific purpose:

Project Structure
workshop1-hello-world/
├── src/

│   ├── main.jsx         ← Entry point; mounts App into index.html
│   └── components/      ← Your reusable components go here
├── index.html           ← Shell HTML; React renders inside <div id="root">

└── package.json         ← Dependencies and scripts

function Greeting({ name }) {

}

export default Greeting
💡 Concept — Props

Props are data passed into a component from its parent. They are read-only — a child component can never modify its own props. Think of props like function arguments.

Understand useState

State is data that changes over time. When state changes, React automatically re-renders the component to reflect the update.

useState syntax
import { useState } from 'react'

// Declares a state variable and its updater function
const [firstName, setFirstName] = useState('')
//     ↑ current value   ↑ function to update it   ↑ initial value
3

Create FullNameApp.jsx with controlled inputs

Create src/components/FullNameApp.jsx. Each input is "controlled" — its value is driven by state, and every keystroke updates state via onChange.

src/components/FullNameApp.jsx
import { useState } from 'react'

function FullNameApp() {
  const [firstName,  setFirstName]  = useState('')
  const [middleName, setMiddleName] = useState('')
  const [lastName,   setLastName]   = useState('')
  const [submitted,  setSubmitted]  = useState(false)

  const fullName = [firstName, middleName, lastName]
    .filter(Boolean).join(' ')

  const initials = [firstName, middleName, lastName]
    .filter(Boolean).map(n => n[0].toUpperCase() + '.').join('')

  return (
    <div>
      <input
        placeholder="First Name"
        value={firstName}
        onChange={(e) => setFirstName(e.target.value)}
      />
      <input
        placeholder="Middle Name (optional)"
        value={middleName}
        onChange={(e) => setMiddleName(e.target.value)}
      />
      <input
        placeholder="Last Name"
        value={lastName}
        onChange={(e) => setLastName(e.target.value)}
      />
      <button onClick={() => setSubmitted(true)}>
        Show Full Name
      </button>

      {submitted && (
        <div>
          <p>Full Name: {fullName}</p>
          <p>Initials: {initials}</p>
        </div>
      )}
    </div>
  )
}

export default FullNameApp

Key concept — HTML inputs always return strings

💡 Important

Even type="number" inputs give you a string. You must convert with parseFloat() before doing arithmetic — otherwise "5" + "3" = "53" instead of 8.

Type conversion
const a = parseFloat(num1)  // "15" → 15
const b = parseFloat(num2)  // "7"  → 7

if (isNaN(a) || isNaN(b)) {
  setError('Please enter valid numbers')
  return
}
if (operation === 'divide' && b === 0) {
  setError('Cannot divide by zero')
  return
}
3

Create Calculator.jsx

Create src/components/Calculator.jsx with state for both numbers, the chosen operation, result, and error message.

src/components/Calculator.jsx (key logic)
import { useState } from 'react'

function Calculator() {
  const [num1, setNum1]           = useState('')
  const [num2, setNum2]           = useState('')
  const [operation, setOperation] = useState('add')
  const [result, setResult]       = useState(null)
  const [error, setError]         = useState('')

  const handleCalculate = () => {
    const a = parseFloat(num1)
    const b = parseFloat(num2)

    if (isNaN(a) || isNaN(b)) {
      setError('Enter valid numbers in both fields.')
      return
    }
    if (operation === 'divide' && b === 0) {
      setError('Cannot divide by zero.')
      return
    }

    setError('')
    const ops = {
      add: a + b,  subtract: a - b,
      multiply: a * b,  divide: a / b,  modulus: a % b
    }
    setResult(ops[operation])
  }

  return (
    <div>
      <input type="number" value={num1} onChange={(e) => setNum1(e.target.value)} />
      <select value={operation} onChange={(e) => setOperation(e.target.value)}>
        <option value="add">+</option>
        <option value="subtract">−</option>
        <option value="multiply">×</option>
        <option value="divide">÷</option>
        <option value="modulus">%</option>
      </select>
      <input type="number" value={num2} onChange={(e) => setNum2(e.target.value)} />
      <button onClick={handleCalculate}>Calculate</button>

      {error && <p style={{color:'red'}}>{error}</p>}
      {result !== null && <p>Result: {result}</p>}
    </div>
  )
}

export default Calculator
